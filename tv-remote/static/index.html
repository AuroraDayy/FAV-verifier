Connect your TV

Your phone and the computer running this must be on the same Wi-Fi as the TV.

1. Find the TV

Enter IP address manually

2. Authorize

Tap below — a 4-digit code will appear on the TV screen.

On the TV: Settings → Network & Internet → Home network → IP control → Authentication: “Normal and Pre-Shared Key”, then set a Pre-Shared Key.

Pairing doesn’t work?
  • On the TV, turn on Settings → Network & Internet → Home network → Remote device settings → Control remotely.
  • For turning the TV on from your phone, also enable Remote start.
  • No remote to change settings? The free Google TV app’s phone remote can do it.
